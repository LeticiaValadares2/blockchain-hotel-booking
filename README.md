
# Blockchain Hotel Booking System

## Project Description

This project is a simple hotel booking system
developed using blockchain technology.

The system uses Ethereum smart contracts to
manage hotel reservations.

## Technologies

- Solidity
- Remix IDE
- Ethereum Blockchain
- Ganache
- Python
- Shell Script

## Main Features

- Book a hotel room
- Confirm a booking
- Cancel a booking
- Refund a cancelled booking
- Record transactions on blockchain

## Users

Hotel Owner:
- Confirms reservations
- Manages booking requests

Guest:
- Books a room
- Makes a payment
- Cancels a pending booking

## Security

The project uses blockchain transactions,
digital signatures and smart contracts.
